# InterconnectHeader1x6

2.54mm ピッチ 1×6 のボード間コネクタ。Links 2 枚構成 (コントロール基板 ↔ メイン基板) の
ブロック毎インターコネクトに使う。

- コントロール基板: `gender="male"` (裏面にピンが伸びる想定)
- メイン基板: `gender="female"` (パネル側の面でソケット受け)
- 必ず x=0 センターで置く。ホール位置が左右対称になり、対向時の整合が
  `mainPinOrder()` によるピン順反転だけで済む
- ポートは pinLabels のラベル名で参照する (`.HDR > .IN` など)
