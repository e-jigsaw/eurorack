# InterconnectHeader1x6

2.54mm ピッチ 1×6 のボード間コネクタ。Links 2 枚構成 (コントロール基板 ↔ メイン基板) の
ブロック毎インターコネクトに使う。

- コントロール基板: `gender="male" layer="bottom"` (裏面実装 — ピンが奥へ伸びる。
  部品反転でラベル→ホールの対応が x ミラーされる)
- メイン基板: `gender="female"` (部品面 = パネル側でソケット受け)、pinLabels は
  `mainPinOrder()` で反転して渡す
- 両基板とも部品面がパネルを向くので、嵌合はグローバル座標の直接一致。
  「control 裏面実装のミラー」と「main のピン順反転」が釣り合って成立する
- 必ず x=0 センターで置く (ホール位置の左右対称を維持)
- PCBA 部品 (datasheet 照合済): オス = BOOMELE 2.54-1x6P (C37208)、メス = XFCN
  PM254V-11-06-H85 (C2832269)。嵌合スタック = オス本体 2.5mm + メス高さ 8.5mm →
  **基板間ギャップ 11.0mm** (オス嵌合ピン 6.0mm がフル挿入)
- ポートは pinLabels のラベル名で参照する (`.HDR > .IN` など)
